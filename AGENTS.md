# AGENTS.md

Instruksi untuk AI apa pun (Codex, Claude, dll.) yang bekerja di repo ini:

1. Baca `PROGRESS.md` terlebih dahulu — berisi rencana, status, dan log perubahan terakhir.
2. Ikuti aturan kerja di `CLAUDE.md`.
3. Untuk pekerjaan UI Flutter, pakai prompt di `docs/Prompt Implementasi UI Flutter.md` (bagian B).
4. Kerjakan hanya sesuai tugas modul (`docs/Modul 1 Pemrograman Mobile.md`); jangan menambah cakupan.
5. Setelah setiap perubahan (kode, Figma, dokumen), perbarui `PROGRESS.md`: centang rencana, perbarui status, dan tambahkan satu baris ke log.
6. Jangan force-push ke `main` repo kelompok.
